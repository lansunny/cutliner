增益来自融合，不是容量

concat 用 75,804 个可训练参数拿到 81.0%， 而 visual_wide 用了 116,620 个（多 54%）只有 74.1%。 参数更少、结果更高，说明提升确实来自声画互补，而不是把模型撑大。

这也是全表最有说服力的一行：它排除了「只是加了参数」这个最常见的替代解释。

两个模态都在起作用

在 dev 上把 concat(seed 42) 的单模态输入置零：

去掉音频 → F1 0.7796 → 0.6381（−14.2 pp）
去掉视觉 → F1 0.7796 → 0.3213（−45.8 pp）

视觉是主干，音频是不可省的增量——两者都不是装饰。

统计口径

按原始视频源配对 bootstrap（2000 次重采样），concat − visual 的 95% 置信区间： F1 [+5.4, +10.5] pp、R@1 [+5.4, +14.9] pp —— 两个下界都大于零。 评测集 215 个独立源，dev 215 个，头训练源 892 个，三者在原始视频层面互不重叠。

边界（来自训练配置，不是我的评论）： PANN 的预训练语料是 AudioSet，而 AVE 正是从 AudioSet 采集而来 —— 所以音频先验不是「未见来源」或零样本证据。 28 类是闭集、1 秒粒度、有声且可见的事件；不等价于任意自然语言查询、长视频定位或整个 Agent 的端到端成功率。 未标注类别被当作负样本，而非经人工确认的「无目标」查询。
